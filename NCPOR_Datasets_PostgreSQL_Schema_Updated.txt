NCPOR Dataset Metadata
PostgreSQL Schema
Schema rebuilt from the supplied NCPOR NPDC dataset export
Source records analyzed:
900 JSON records and 900 CSV rows. The supplied records expose NCPOR NPDC metadata
such as title, abstract, purpose, release information, scientific classification, project details, personnel, data center,
instrument, platform, location and resource links.
Design principle: preserve the source metadata faithfully, normalize repeated entities for relational querying, and retain the original raw
metadata in JSONB so fields that are sparse or added by NCPOR later are not lost.
1. What the supplied dataset actually contains
The export includes a source identifier, title, abstract, release date and URLs at the record level. A representative record
also contains structured Basic Information, Science Keywords, Project Details, Summary, Dataset Citation, Scientist Details,
Data Center, Instrument Details, Location, Platform and Data Set Progress.
